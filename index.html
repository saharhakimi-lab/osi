🔌 שכבה 1 - השכבה הפיזית (Physical Layer)

⚡ תפקיד השכבה

הקרקע המוצקה של הרשת! השכבה הפיזית אחראית על העברת הביטים הגולמיים (01010101) על גבי התווך הפיזי. היא ממירה את הביטים לפולסים חשמליים (בכבלי נחושת), פולסים של אור (בסיבים אופטיים), או גלי רדיו (ב-Wi-Fi).

🛠️ תשתיות וציוד

נחושתUTP Cat6 / RJ-45
אופטיקהSingle/Multi-Mode
ישןHub / Repeaters
אלחוט2.4GHz / 5GHz

מספר:Layer 2
שם:Data Link
PDU:Frame

🔗 שכבה 2 - שכבת קו הנתונים (Data Link Layer)

⚡ תפקיד השכבה

שכבת התקשורת ברשת המקומית (LAN)! היא עושה אריזה מחדש של המידע ל-Frames (מסגרות) ומצמידה להן כתובות פיזיות (MAC Addresses). היא מבטיחה שהמידע יעבור בבטחה ובלי שגיאות בין שני רכיבים הנמצאים באותו המקטע הפיזי.

🛠️ רכיבים ופרוטוקולים

כתובתMAC Address
תקןEthernet (802.3)
תרגוםARP Protocol
חומרהSwitch / NIC

🔗 לחץ להרחבה

שכבה 2 מחולקת לשתי תתי-שכבות: LLC (בקרת קישור לוגי) ו-MAC (בקרת גישה למדיה). הסוויטש שלכם עובד בדיוק בשכבה הזו!

מספר:Layer 3
שם:Network
PDU:Packet
רכיב:Router

🌐 שכבה 3 - שכבת הרשת (Network Layer)

⚡ תפקיד השכבה

שכבת הניתוב והכתובות הלוגיות! היא אחראית על העברת החבילות (Packets) מקצה לקצה בין רשתות שונות ונפרדות. השכבה מוסיפה לכל חבילה את כתובת ה-IP של המקור ואת כתובת ה-IP של היעד ומחליטה באיזה נתיב הכי כדאי לנתב אותה.

🛠️ טכנולוגיות ופרוטוקולים

כתובותIPv4 / IPv6
בקרהICMP (Ping)
ניתובOSPF, BGP, RIP
חומרהRouter / L3 Switch

מספר:Layer 4
שם:Transport

זיהוי:Ports

🚚 שכבה 4 - שכבת התחבורה (Transport Layer)

⚡ תפקיד השכבה

אחראית על העברת הנתונים בין תהליכים (Process-to-Process). היא קוטעת את המידע הפיזי למקטעים קטנים (Segments), ומצמידה מספרי פורטים (Ports) כדי לדעת לאיזה אפליקציה המידע שייך במחשב (למשל פורט 80 לגלישה, פורט 25 למייל).

🛠️ שני הפרוטוקולים המובילים

TCP (אמין)Three-Way Handshake
UDP (מהיר)ללא אישור קבלה
פורטים0 עד 65,535
בקרהFlow Control

🔥 טיפ מטורלל של האחוואנים

זוכרים? TCP שולח מכתב רשום עם אישור מסירה (SYN -> SYN-ACK -> ACK). לעומתו, UDP מטיף חבילות באוויר כמו ספאם ואינו בודק אם קיבלתם!

שם:Session

🗣️ שכבה 5 - שכבת השיחה (Session Layer)

⚡ תפקיד השכבה

המרכזיה שמנהלת את הדיאלוג! שכבה זו אחראית לפתוח, לשמור ולסגור את ה"שיחות" (Sessions) בין שני מחשבים ברשת. היא דואגת שהתקשורת תישאר פתוחה כל עוד מעבירים מידע, ותסגר מיד כשמסיימים כדי לא לבזבז משאבים.

🛠️ טכנולוגיות ופרוטוקולים

שיחותNetBIOS
שיתוףSMB / RPC
מנהרהPPTP
סנכרוןCheckpoints

🔥 טיפ מטורלל של האחוואנים

שכבת השיחה מציבה "Checkpoints" במהלך הורדת קבצים גדולים. אם החיבור מתנתק באמצע, היא יודעת להמשיך בדיוק מהנקודה שנעצרה ולא להתחיל מחדש!

מספר:Layer 6
שם:Presentation
PDU:Data
תפקיד:הצפנה, דחיסה

🎨 שכבה 6 - שכבת התצוגה (Presentation Layer)

⚡ תפקיד השכבה

השכבה שדואגת שהמידע יגיע בפורמט שהמקבל יוכל להבין! היא מבצעת תרגום בין קידודים שונים (למשל ASCII ל-UTF-8), דוחסת את המידע כדי שיטוס מהר יותר, ומבצעת הצפנה (Encryption) ופענוח (Decryption) לשמירה על אבטחה.

🛠️ פורמטים ופרוטוקולים נפוצים

הצפנהSSL / TLS
תמונותJPEG, PNG
וידאוMP4, MP3
קידודASCII, UTF-8

🔥 טיפ מטורלל של האחוואנים

כשאתם נכנסים לאתר מאובטח והמנעול הירוק דולק (HTTPS), הצפנת ה-TLS מתרחשת בשכבה הזו בדיוק!

מספר:Layer 7
שם:Application
PDU:Data
רכיב:דפדפן, מייל

📱 שכבה 7 - שכבת האפליקציה (Application Layer)

⚡ תפקיד השכבה

השכבה הראשונה שבאמצעותה המשתמש מקיים אינטראקציה עם הרשת. היא מספקת את ממשקי התקשורת והפרוטוקולים ישירות לאפליקציות שלכם (דפדפן האינטרנט, תוכנת ה-Email, או תוכנת העברת הקבצים).

🛠️ פרוטוקולים מרכזיים

גלישהHTTP / HTTPS
שמותDNS
דוארSMTP / IMAP
קבציםFTP / SFTP
