⚡ אופן פעולה

מחשב הוא רכיב הקצה (End-Device) שבו הכל מתחיל ונגמר! הוא מייצר את המידע בשכבת האפליקציה (למשל הודעת וואטסאפ, בקשת HTTP בדפדפן או סטרימינג ביוטיוב), עובר את כל תהליך ההכמסה (Encapsulation) דרך סטאק ה-TCP/IP, ושולח אותה החוצה. כשהוא מקבל חבילה - הוא מפרק אותה מהביטים ועד לטקסט/וידאו שאתם רואים במסך.

🛠️ נתונים טכניים מרכזיים

כתובת לוגיתIP Address (IPv4/IPv6)
מערכת הפעלהWindows / Linux / macOS
פרוטוקולי יישוםHTTP, HTTPS, FTP, DNS
ניהול פורטיםSockets (1-65535)

🔥 טיפ מטורלל של האחוואנים

המחשב מריץ טבלת ARP פנימית! תרשמו ב-CMD שלכם arp -a ותראו איך המחשב זוכר איזה כתובת IP שייכת לאיזה כתובת MAC פיזית ברשת המקומית שלכם!

💳 כרטיס רשת (Network Interface Card - NIC)

⚡ אופן פעולה

הכרטיס רשת הוא המתרגם והשומר בכניסה למחשב! הוא לוקח את המידע הדיגיטלי מהמעבד והזיכרון, מקודד אותו לאותות חשמליים, אופטיים או גלי רדיו, ושולח אותו לתווך התקשורת. בנוסף, על כרטיס הרשת צרובה כתובת ה-MAC הפיזית הבלעדית שלו שלא משתנית לעולם!

🛠️ נתונים טכניים מרכזיים

🔀 מתג רשת (Switch - L2)

⚡ אופן פעולה

הסוויטש הוא המרכזיה החכמה של הרשת המקומית (LAN). כשמגיעה אליו מסגרת (Frame), הוא מסתכל על כתובת ה-MAC של היעד, בודק בטבלת ה-MAC הפיזית שלו באיזה פורט היעד נמצא, ושולח את המידע **רק לפורט הזה**! בשונה מהרכזת הישנה (Hub) שהיתה צועקת לכולם (Broadcast).

🛠️ נתונים טכניים מרכזיים

חיבור בין סוויצ'יםTrunk Port (802.1Q Tagging)
אבטחת פורטיםPort Security (Sticky MAC)
מניעת לולאותSTP (Spanning Tree Protocol)

🔥 טיפ מטורלל של האחוואנים

אם הסוויטש לא מכיר את כתובת ה-MAC של היעד, הוא יבצע היצפה (Unknown Unicast Flooding) וישלח את המסגרת לכל הפורטים חוץ מהפורט שנכנסה ממנו, עד שהוא ילמד אותה!

⚡ אופן פעולה

הראוטר הוא מנהל התנועה העולמי! התפקיד שלו הוא לקשר בין רשתות שונות נפרדות (למשל הרשת הביתית שלכם לרשת האינטרנט העולמית). הראוטר בוחן את כתובת ה-IP של היעד בכל חבילה, בודק בטבלת הניתוב שלו (Routing Table) מה המניע/הנתיב הכי טוב להגיע לשם, ומעביר אותה הלאה.

🛠️ נתונים טכניים מרכזיים
